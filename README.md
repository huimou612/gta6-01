Solmar — an original 3D open-world crime game in the spirit of GTA 6. Drive and walk a sun-soaked coastal city, steal cars, dodge the police, and run three story missions as Milo Vega, wheelman for Vega Motors. Built with three.js, playable offline in a desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
